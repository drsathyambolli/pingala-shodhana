# pingala-shodhana (Python package)

Sanskrit metre analysis: scansion, identification, diagnosis, metre repair (Chando-Sahāyaka) and lakṣaṇa reading (Lakṣaṇa-Yantra).

```bash
pip install -e .
pingala identify "या कुन्देन्दुतुषारहारधवला या शुभ्रवस्त्रावृता"
```

See the repository README for full documentation.
